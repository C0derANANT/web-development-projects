Made while learning

Pursuit is my first iOS app. I'm building it in seven days, from 17 to 24 November 2026, while learning Swift. This page is my first scroll-animated website.

Three things I learned so far

  1. An app screen is a description. When the data changes, SwiftUI redraws the screen for me.
  2. Save straight away. An application added just before closing the app got lost until I fixed it.
  3. Never rename a saved value. Old data still uses the old name, so I add new options instead.
